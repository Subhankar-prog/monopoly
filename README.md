# 🎲 Monopoly Online Multiplayer

A modern multiplayer Monopoly-inspired board game built using **React, TypeScript, Node.js, Express, and Socket.IO**. Experience strategic gameplay with real-time multiplayer, immersive animations, property management, auctions, trading, and complete Monopoly mechanics.

Designed for **2–5 players**, the game provides a smooth and engaging experience with a server-authoritative architecture, ensuring fair gameplay and seamless synchronization across all connected players.

---

## ✨ Features

### 🎮 Gameplay

- Real-time Online Multiplayer (2–5 Players)
- Room Creation & Join via Room Code
- Complete Turn-Based Gameplay
- Dice Roll Animation
- Property Purchase System
- Property Trading
- Property Auctions
- House & Hotel Construction
- Mortgage & Redemption
- Chance & Community Chest Cards
- Jail System
- Bankruptcy Handling
- Winner Detection

## 🚀 Getting Started

### Clone Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
pnpm install
```

### Start Development

```bash
pnpm run dev
```

### Multiplayer Mode

```bash
pnpm run dev:multi
```

### Production Build

```bash
pnpm build
```
